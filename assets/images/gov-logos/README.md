# Government logos

These files are the official marks used in the homepage “Trusted by government” section. They are stored locally so the page does not hotlink them. Each file is a PNG with a transparent background. They have not been redrawn or recoloured. Extra transparent padding has been trimmed, leaving a small clear margin so the artwork is not cut.

Each file is the body’s current lockup. Older names (DLUHC, DCLG) and the withdrawn Jobcentre Plus ESF mark were rejected.

| Body | File | Source and why it is the current official mark |
| --- | --- | --- |
| Skills England | `skills-england.png` | [Skills England black logo](https://skillsengland.education.gov.uk/site/images/logo/SkillsEnglandLogoBlack.svg), the same lockup as the site header with black artwork (`fill: #000`) instead of white. Rendered to a transparent PNG. The white file would disappear on this section’s white ground, so the navy backing is not used. |
| Government Commercial Agency | `government-commercial-agency.png` | [GCA website, landscape black brand mark](https://www.gca.gov.uk/assets/images/GCA_linear_black.png). The published PNG is already black on a transparent background. Only the empty margin was trimmed. Brand guidance: [gca.gov.uk brand guidelines](https://www.gca.gov.uk/government-commercial-agency-style-guide/brand-guidelines). |
| Greater London Authority | `greater-london-authority.png` | [Wikimedia Commons file](https://commons.wikimedia.org/wiki/File:Greater_London_Authority_logo.svg), a public-domain reproduction of the wordmark credited to [london.gov.uk](https://www.london.gov.uk/). Rendered to a transparent PNG. |
| HM Prison & Probation Service | `hm-prison-and-probation-service.png` | [Wikimedia Commons file](https://commons.wikimedia.org/wiki/File:HMPPS.png), the standard HMPPS lockup (vertical rule, Royal Arms and name).
